桌面倒计时

一款简洁的 Windows 桌面倒计时工具，常驻屏幕角落，实时显示重要日期剩余时间。

功能特性

  • 桌面常驻：主窗口固定在屏幕四角（右上/左上/左下/右下），支持置顶/置底
  • 多倒计时管理：同时追踪多个重要日期，精确到时分
  • 智能提醒：剩余不足 1 天时数字自动变红提醒
  • 农历显示：集成农历日期和传统节日
  • 月历面板：显示当月日历，高亮今天和有倒计时的日期，支持翻月浏览
  • 主题切换：深色/浅色主题，支持随时间自动切换（7:00-19:00 浅色）
  • 窗口缩放：10%~500% 等比缩放，适配各种分辨率显示器
  • 系统托盘：最小化到托盘，防止误关闭
  • 开机自启：支持开机自动启动
  • 一键添加倒计时：顶部按钮快速创建，内置学习场景常用名称（考试结束、交卷、上课等），支持任意日期与时长
  • 全屏显示：时间和每条倒计时都可一键全屏，倒计时不足 1 天红色大字提醒，并同步显示当前时间
  • 内置说明书：设置窗口中可直接查看完整使用说明

版本历史

v1.5（2026-10-19）

问题修复

  • 修复通过「添加倒计时」新增条目后，所有倒计时名称颜色被重置为深色主题白色的问题（重建列表时未应用当前主题，现已在创建每行时同步主题色）

v1.4（2026-10-17）

新增功能

  • 设置窗口新增「说明书」按钮，内置完整使用说明书，支持滚动与 Esc 关闭
  • 新增一键全屏：顶部「全屏时间」按钮、每条倒计时右下角「全屏」按钮，同时保留长按 0.5 秒的入口
  • 全屏倒计时新增当前时间显示（字号为倒计时数字的 1/4，位于截止时间下方）
  • 添加倒计时支持名称下拉预设：考试结束、结束、考试开始、交卷、上课、下课、早/晚自习结束、模拟考试、期中/期末考试、放假、开学、高考、考研，也可自定义输入
  • 添加倒计时支持任意年月日时分（不再限制 24 小时），快捷时长新增 1 天、7 天
  • 添加倒计时实时预览结束时刻与剩余时间，选择过去时间时红字提示并禁止创建；新增备注填写；名称框默认显示“请输入文本或选择名称”占位提示
  • 托盘菜单「新建短时倒计时」同步改名为「添加倒计时」
  • 新增 Windows 7/8/8.1 兼容版（Countdown-1.5-Win7.zip），内置 Java 8 运行环境，解压后运行 Countdown.vbs 或 启动.bat 即可使用，无需安装 Java

优化改进

  • 顶部按钮统一重排为紧凑左侧布局（设置 / 添加倒计时 / 全屏时间），远离屏幕右上角，避免误触其他软件的关闭按钮
  • 时间模块恢复纯净居中显示，功能按钮全部收口到顶部栏与倒计时行内
  • 结束时间内部保留秒，快捷创建的倒计时精确到秒，界面仍按 HH:mm 展示

问题修复

  • 修复全屏倒计时当前时间使用 Bahnschrift 字体导致中文“现在”显示为方框的问题（改用微软雅黑）
  • 优化添加倒计时对话框年月日联动逻辑，程序化填充时不再误触发“手动修改”回调
  • 修复说明书中关于窗口关闭行为的错误描述（本程序为无边框悬浮窗，通过托盘图标显隐）

v1.3（2026-10-14）

新增功能

  • 月历支持点击日期显示方框标记
  • 月历显示传统节日（覆盖农历显示）
  • 月历翻月时自动调整窗口高度，避免挤压倒计时列表

优化改进

  • 内存占用优化：缓存 Font/LunarCalendar 对象，减少重复创建
  • 农历/节日标签按需更新，减少 UI 重绘
  • JVM 参数优化：限制堆内存 64MB，禁用硬件加速，总内存占用降至约 105 MB

问题修复

  • 修复月历切换时窗口抖动问题（合并大小/位置设置为原子操作）

  • 新增半透明窗口选项
  • 新增深浅主题自动切换
  • 优化托盘菜单为 Swing 组件，修复中文显示方框问题
  • 优化 UI 细节（字体、间距、圆角等）
